<summary><h2 id="installation">🚀 Quick Start</h2></summary>

<div align="center">
  <img src="https://raw.githubusercontent.com/gist/0xShapeShifter/5bac4419caa722bdabc4a2a1a5c8446f/raw/9e5a34e5bab5bd8af7d990f6a65e1e664b66db4e/installation-animated.svg" width="300" alt="Installation" />
</div>

1. **Clone the repository**
   ```bash
   git clone https://github.com/yourusername/campus-finder.git
   ```

2. **Navigate to project directory**
   ```bash
   cd campus-finder
   ```

3. **Install dependencies**
   ```bash
   npm install
   ```

4. **Run development server**
   ```bash
   npm run dev
   ```

5. **Open [http://localhost:3000](http://localhost:3000) to view the app**

</details>
